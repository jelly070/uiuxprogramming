### Memory Up - 기억력 훈련 설정

## 사용자와 목표
- 사용자 : 기억력을 향상시키고 싶은 사람
- 목표 : 기억력 훈련 조건을 설정하고, 설정한 내용을 확인한다.

## 사용자의 흐름
1. 훈련 결과 저장에 동의하고 '훈련 시작하기'를 누른다.
2. 학습자 이름을 입력하고, 비어 있으면 같은 단계에서 안내를 받는다.
3. 기억력 훈련의 난이도를 선택하고 필요하면 훈련 시간을 설정한다.
4. 이름과 난이도, 설정한 훈련 시간을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오
1. 시작과 훈련 결과 저장 안내
- 행동, 이벤트 : 기존 동의 체크박스를 선택하고 '훈련 시작하기'를 클릭한다.
- 조건 : 훈련 결과 저장에 동의했는가?
- 반응, 다음 상태 : 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 훈련 결과 저장 목적을 설명하는 안내 팝업이 열린다.
                    팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
                    '동의하고 설정 시작하기'를 누르면 학습자 이름 입력 화면을 연다.
2. 학습자 이름 입력
- 행동, 이벤트 : 이름을 적고 '훈련 조건 선택하기'를 클릭한다.
- 조건 : 앞뒤 공백을 지운 이름이 비어 있는가?
- 반응, 다음 상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                    값이 비어있으면 저장하고 조건 선택으로 이동한다.
3. 조건 선택
- 행동, 이벤트 : 기억력 훈련 난이도를 선택하고 필요하면 훈련 시간을 설정한 뒤 '내용 확인하기'를 클릭한다.
- 조건 : 훈련 시간을 설정했는가?
- 반응, 다음 상태 : 설정한 경우 선택한 훈련 시간을 표시한다.
4. 내용 확인
- 행동, 이벤트 : 이름, 난이도, 훈련 시간을 확인하고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건 : 수정인가, 완료인가?
- 반응, 다음 상태 : 수정하면 기존 설정값을 유지하고 조건 선택 화면으로 돌아간다.
                    완료하면 설정 완료 안내 화면으로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트 : 완료 안내를 확인하고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태 : 이름, 난이도, 훈련 시간 및 진행 상태를 초기화하고 이름 입력 화면부터 다시 시작한다.
                    이미 확인한 훈련 결과 저장 동의와 기존 기능은 유지한다.

## 주요 기능
- 다크 모드 전환
- 학습자 이름 입력 및 글자 수 표시
- 훈련 결과 저장 동의
- 기억력 훈련 콘텐츠 탭 전환
- 훈련 난이도 및 시간 설정
- 설정 내용 확인 및 다시 설정하기

## 테스트 결과
- 빈 이름 입력 시 오류 메시지 표시 확인
- 이전 단계 이동 시 입력값 유지 확인
- 난이도 및 훈련 시간 변경 시 확인 화면 반영 확인
- 설정 완료 및 다시 설정하기 기능 확인

### 중간고사 - 기억력 미니 퀴즈
## 주요 기능
- 기억력 미니 퀴즈 단계별 화면 전환
- 객관식 정답 선택 및 결과 확인
- 그림 다시보기 및 퀴즈 재도전하기

## 사용자 흐름
1. 그림 기억하기 : 사과, 토끼, 고래 그림을 기억한 후 '문제 풀기'를 클릭한다.
2. 문제 풀기 : 선택할 수 있는 정답 중 기억나는 그림을 선택하고 '정답 확인하기'를 클릭한다.
3. 조건 확인 : 답을 선택하지 않았다면 '정답을 선택해주세요.'라는 오류 메시지를 표시한다.
4. 결과 확인 : 사과를 선택하면 정답 메세지를, 다른 항목을 선택하면 오답 메시지를 표시한다.
5. 다시 설정 : '다시보기'로 그림을 확인하거나, '다시 도전하기'로 결과를 초기화한다.

## 테스트 결과
- 다크 모드 전환
- 기억력 미니 퀴즈 선택 시 이동 확인
- 퀴즈 단계별 화면 전환 확인
- 정답 미선택 시 오류 메시지 표시 확인
- 정답 및 오답 선택에 따른 결과 표시 확인
- 그림 다시보기 및 퀴즈 초기화 기능
