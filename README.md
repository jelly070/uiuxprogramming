### Memory Up - 기억력 훈련 설정

## 사용자와 목표
- 사용자 : 기억력을 향상시키고 싶은 사람
- 목표 : 기억력 훈련 조건을 설정하고, 설정한 내용을 확인한다.

## 사용자의 흐름
1. 훈련 결과 저장에 동의하고 '훈련 시작하기'를 누른다.
2. 학습자 이름을 입력하고, 비어 있으면 같은 단계에서 안내를 받는다.
3. 기억력 훈련의 난이도를 선택하고 필요하면 훈련 시간을 설정한다.
4. 이름과 난이도, 설정한 훈련 시간을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터렉션 시나리오
1. 훈련 정보 입력
- 행동, 이벤트 : 훈련 제목과 학습자 이름을 입력하고 '훈련 조건 선택하기'를 클릭한다.
- 조건 : 훈련 제목이 비어 있거나 2자 미만인가?
- 반응, 다음 상태 : 조건을 충족하지 못하면 오류 문구를 표시하고 입력창에 초점을 둔다. 조건을 충족하면 훈련 조건 선택 화면으로 이동한다.
- 입력하는 동안 글자 수와 조건 충족 여부를 안내한다.

2. 훈련 조건 선택
- 행동, 이벤트 : 훈련 난이도를 선택하고 필요하면 훈련 시간을 설정한다.
- 조건 : 훈련 시간 설정 체크박스를 선택했는가?
- 반응, 다음 상태 : 체크박스를 선택하면 시간 선택 영역이 나타나고 입력할 수 있다. 선택을 해제하면 영역이 숨겨지고 입력 요소가 비활성화된다.

3. 입력 내용 확인
- 행동, 이벤트 : 훈련 제목, 학습자 이름, 난이도, 시간을 확인한다.
- 조건 : 수정이 필요한가?
- 반응, 다음 상태 : '정보 수정' 또는 '조건 수정'을 선택하면 기존 입력값을 유지한 채 해당 단계로 돌아간다.

4. 계획 제출 및 저장
- 행동, 이벤트 : '계획 저장하기'를 클릭한다.
- 조건 : 필수 입력 조건을 충족했는가?
- 반응, 다음 상태 : 조건을 충족하지 못하면 제출을 막고 오류를 안내한다.
- 제출 중에는 '저장하는 중...' 문구를 표시하고 버튼을 비활성화하여 중복 제출을 방지한다.
- 저장에 성공하면 완료 안내 화면으로 이동한다.
- 저장에 실패하면 오류 문구를 표시하고 입력값을 유지하여 다시 시도할 수 있도록 한다.

5. 저장한 계획 관리
- 행동, 이벤트 : 내 훈련 계획에서 저장한 계획을 확인한다.
- 반응, 다음 상태 : '내용 보기'를 누르면 상세 내용을 확인할 수 있다. '계획 취소하기'를 누르면 취소 상태로 변경되고, '취소 되돌리기'를 통해 복구할 수 있다.

6. 새 계획 만들기
- 행동, 이벤트 : 저장 완료 후 '새 계획 만들기'를 클릭한다.
- 반응, 다음 상태 : 입력값과 글자 수, 오류 및 성공 안내, 제출 버튼 상태가 초기화되고 첫 번째 단계로 돌아간다.

### 중간고사 - 기억력 미니 퀴즈
## 주요 기능
- 기억력 미니 퀴즈 단계별 화면 전환
- 객관식 정답 선택 및 결과 확인
- 그림 다시보기 및 퀴즈 재도전하기

## 사용자 흐름
1. 그림 기억하기 : 사과, 토끼, 고래 그림을 기억한 후 '문제 풀기'를 클릭한다.
2. 문제 풀기 : 선택할 수 있는 정답 중 기억나는 그림을 선택하고 '정답 확인하기'를 클릭한다.
3. 조건 확인 : 답을 선택하지 않았다면 '정답을 선택해주세요.'라는 오류 메시지를 표시한다.
4. 결과 확인 : 사과를 선택하면 정답 메세지를, 다른 항목을 선택하면 오답 메시지를 표시한다.
5. 다시 설정 : '다시보기'로 그림을 확인하거나, '다시 도전하기'로 결과를 초기화한다.

## 테스트 결과
- 다크 모드 전환
- 기억력 미니 퀴즈 선택 시 이동 확인
- 퀴즈 단계별 화면 전환 확인
- 정답 미선택 시 오류 메시지 표시 확인
- 정답 및 오답 선택에 따른 결과 표시 확인
- 그림 다시보기 및 퀴즈 초기화 기능

### 9주차 - 입력 폼 개선
## 추가 및 수정 기능
- 훈련 제목 필수 입력(2~60자) 및 글자 수 표시
- 입력 조건 충족 여부에 따른 성공, 오류 안내
- 체크박스 선택에 따른 훈련 시간 입력 영역 표시 및 비활성화
- 제출 중 진행 문구 표시 및 중복 제출 방지
- 계획 저장 및 성공, 실패 처리
- 새로운 계획을 만들면 입력값과 상태 초기화

## 동작 확인 순서
1. 제목을 비우거나 한 글자만 입력해 오류 확인
2. 2자 이상 입력해 오류 해제 및 성공 안래 확인
3. 훈련 시간 체크박스 선택 및 해제 확인
4. 계획 저장 시 제출 상태와 완료 안내 확인
5. 새 게획 만들기 시 초기화 확인
