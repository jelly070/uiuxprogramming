## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁게 보임

### 수정한 내용 
- viewport 메타 태그 추가
- 콘텐츠에 width, max-width 함께 사용
- 기능 카드 목록을 반응형 Grid로 변경
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성

### 확인할 화면 너비
1100px / 769px / 768px / 390px

## 5주차 사용자 행동에 반응하는 화면 만들기

### 추가한 기능
이메일 입력을 통한 훈련 소식 신청 기능

### 사용자 행동 
이메일을 입력하고 신청 버튼 클릭

### 화면 변화
- 이메일 미입력 시 안내 메세지 표시
- 신청 버튼 완료 시 성공 메시지와 스타일 변경
- 버튼 문구를 '신청 완료'로 변경하고 비활성화

### 사용한 코드
- querySelector()로 HTML 요소 선택
- addEventListener()로 폼 제출 이벤트 연결
- if 조건문으로 이메일 입력 여부 확인
- textContent로 안내 문구 변경
- classList.add("is-success")로 성공 상태 스타일 적용
- disabled로 신청 완료 버튼 비활성화
