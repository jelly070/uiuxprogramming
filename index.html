서비스 소개

반복 학습으로 키우는 기억력

다양한 암기 활동과 반복 학습을 통해 기억력 향상을 돕는 서비스입니다.

단계별 훈련과 기억력 테스트를 통해 학습 결과를 확인하고, 자신에게 맞는 학습 방법을 찾아갈 수 있습니다.

훈련 기능

  • 단계별 암기 훈련

    난이도에 따라 단어와 정보를 암기하며 기억력을 훈련합니다.

  • 기억력 테스트

    학습한 내용을 퀴즈로 확인하고 기억한 정보를 점검합니다.

  • 학습 결과 확인

    테스트 결과와 정답률을 확인하고 부족한 부분을 파악합니다.

이용 방법

  1. 회원가입 후 로그인
  2. 원하는 암기 훈련의 난이도를 선택합니다.
  3. 제시된 단어와 정보를 암기합니다.
  4. 기억력 테스트를 통해 학습한 내용을 확인합니다.
  5. 테스트 결과를 확인하고 부족한 부분을 반복 학습합니다.
